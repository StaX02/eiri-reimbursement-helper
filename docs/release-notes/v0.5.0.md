# v0.5.0

提供 Windows 10/11 x64 MSI 安装包及免安装 ZIP，内置 .NET、Python、PDF 渲染与 OCR 依赖和模型。

## 自 v0.4.0 以来的更新

- 订单和报销单完成全部报销里程碑后自动归档，支持查看归档资料及取消报销单归档。
- 展示和刷新钉钉审批流程状态，区分已同意、已拒绝和已撤销；被拒绝或撤销后支持重新提审。
- 保存并展示钉钉审批编号。
- 已同意的报销单可导出审批 PDF：首页包含已提交表单数据，后续拼接关联订单的辅助材料，支持批量导出。
- 按发票列坐标提取发票明细，改善项目名称识别。
- 改善窗口边框和归档窗口位置，修复最大化窗口遮挡任务栏的问题。

## 安装

- MSI 支持选择安装目录、当前用户资料库目录及桌面快捷方式，升级保留已有目录和资料。
- 卸载默认保留资料库；更换资料库位置请使用应用内备份和恢复。
- MSI 和 ZIP 均提供 SHA-256 校验文件。安装包未做代码签名。

## 验证

- Release 配置下 190 项 .NET 测试通过。
- 20 项 Python worker 测试通过。
- 打包后的独立 worker 通过 PDF 文本提取、渲染、OCR 和审批 PDF 导出验证。
- MSI 完整 payload、内嵌 CAB、升级规则、6 帧图标及安装选项和删除边界验证通过。
- 实际安装、维护重装、v0.4.0 → v0.5.0 升级、默认保留资料卸载、更换资料目录及明确删除资料卸载通过。
- ZIP 内 984 个文件均与发布目录的 SHA-256 一致。
- 本次测试及构建关闭 NuGet 在线漏洞查询；未完成在线依赖漏洞审计。
