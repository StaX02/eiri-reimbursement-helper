# v0.6.0

发布日期：2026-10-29。提供 Windows 10/11 x64 MSI 安装包及免安装 ZIP，内置 .NET、Python、PDF 渲染与 OCR 依赖和模型。下载入口：[v0.6.0 Release](https://github.com/StaX02/eiri-reimbursement-helper/releases/tag/v0.6.0)。

## 自 v0.5.0 以来的更新

- 新增“选项 → 设置”，集中管理钉钉连接、提审信息和默认导出目录；普通报销资料与审批 PDF 共用导出目录设置。
- 启动时按连接状态尝试钉钉重连，连接成功后刷新审批流程；资料库迁移至 schema 14，保存上次连接失败标记。
- 改善低质量 PDF 文本识别：自动调用本地 OCR，保留可靠文本结果、补齐缺失字段，并提示冲突或未解决的低质量页。
- 统一订单与报销单详情的文件导入区域，支持点击、键盘操作和拖放。
- 修复 Python 依赖审计发现项：更新 Pillow 至 `13.0.0`、pypdf 至 `6.21.2`、urllib3 至 `2.8.0`、certifi 至 `2026.10.19`，并更新构建工具；修复后复审未发现已知漏洞。
- 整理文档导航、开发与交付指南、领域词汇和 worker 协议说明。

本次功能源码基线为 `ddc0a28`，桌面项目版本更新为 `0.6.0`，同时更新审计涉及的依赖。交付范围包含已有功能和本次依赖更新；[开发计划](../development-plan.md)中的 S1–S4 稳定性改动继续保留为后续工作。

## 安装

- MSI 支持选择安装目录、当前用户资料库目录及桌面快捷方式，升级规则沿用已有目录和资料。
- 卸载默认保留资料库；更换资料库位置请使用应用内备份和恢复。
- MSI 和 ZIP 均附带 SHA-256 校验文件；MSI 的签名状态为 `NotSigned`。
