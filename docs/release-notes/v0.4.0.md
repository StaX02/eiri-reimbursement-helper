# v0.4.0

提供 Windows x64 MSI 安装包，包含 .NET 应用、Python 运行时、PDF 渲染、OCR 依赖及模型。

## 安装与卸载

- 中文安装表单支持选择应用安装位置和当前 Windows 用户的数据保存位置。
- 自动添加开始菜单快捷方式，可选添加桌面快捷方式。
- 升级和修复沿用已有目录并保留资料库。
- 卸载默认保留数据，可明确选择永久删除当前用户的数据库和受管材料。
- 静默安装支持 `INSTALLFOLDER`、`DATADIRECTORY` 和 `ADDDESKTOPSHORTCUT`；静默卸载仅在 `DELETEAPPDATA=1` 时清理数据。
- 提供 MSI、免安装 ZIP 和各自的 SHA-256 校验文件。安装包未做代码签名。

数据保存在专用 `EiriReimbursementHelper` 文件夹；更换位置不会自动迁移旧资料库，迁移请使用应用内备份与恢复。卸载保留外部导出、外部备份、其他 Windows 用户的资料库及所选目录内无关文件。

## 自 v0.3.0 以来的应用更新

- 增加报销单、订单绑定、报销单 PDF 识别、报销里程碑与详情自动保存。
- 导出按总金额命名，增加平铺的打印材料目录。
- 接入钉钉凭据、本地提审信息、动态审批表单及报销审批流程。
- 改善附件打开、多个发票号显示、清单密度和应用主题。
- 修复再次打开版本十资料库时的数据保留问题。
